# Google Play 商店頁面素材

Play Console →「拓展用戶」→「商店資訊」→「主要商店資訊」，依下表填入。預設語言選 **中文（台灣）– zh-TW**。

## 文字

### 應用程式名稱（上限 30 字）

```
小小遊戲屋：幼兒益智小遊戲
```

### 簡短說明（上限 80 字）

```
翻牌記憶、注音配對、數數、著色、描字等 12 款幼兒小遊戲，無廣告、可離線玩。
```

### 完整說明（上限 4000 字）

```
小小遊戲屋是一套給 3 到 6 歲孩子玩的益智小遊戲合集，一共 12 款。畫面大、按鈕大，孩子用手指點一點、滑一滑就會玩；遊戲裡會用台灣國語唸出題目和名稱，還不識字也能自己玩。

所有遊戲都「不會失敗」：沒有倒數計時、答錯不扣分，選錯的答案會淡掉，最後一定找得到正確答案，過關至少拿到 2 顆星。讓孩子在鼓勵中學習，而不是在挫折中放棄。

【12 款遊戲】
・翻翻樂：翻開卡片找出一樣的，配對成功會唸出名稱，有動物、水果、交通工具三種主題
・敲敲地鼠：地鼠冒出來就敲一下，還有「只敲指定動物」和「只敲指定數字」模式
・顏色小籃子：把東西放進一樣顏色的籃子，認識紅、黃、藍、綠、紫、橘
・拼拼樂：4、6、9 片拼圖，可以拖曳，也可以先點拼圖片再點位置
・接水果：手指左右移動籃子接住水果，練習手眼協調
・ㄅㄆㄇ配對：看圖找注音、看注音找圖，認識 21 個聲母
・洞洞吃光光：按住畫面滑動帶著洞洞走，由小吃到大，有公園、城市、農場、海邊、太空、恐龍世界六個場景
・消消樂：三個一樣排一排就消掉，沒有步數限制，停下來會提示
・跳跳恐龍：點一下就跳，帶小恐龍跑到終點
・數一數：點一下東西就標上號碼，像用手指一個一個數，還有加法練習
・著色本：選顏色、點一下就塗滿，有小貓、小魚、汽車、房子、花朵、火箭，作品會自動保存
・描描寫寫：跟著筆順描數字 0–9 和注音符號，綠點告訴你從哪裡開始

【給家長】
・完全沒有廣告，也沒有任何付費項目或內購
・不需要註冊或登入，不收集任何個人資料
・所有遊戲都內建在 App 中，不需要網路，出門在外也能玩
・難度可以調整，從簡單慢慢進步到挑戰
・適合手機與平板，平板上玩起來更大更清楚

【語音小提醒】
遊戲會唸出題目與鼓勵的話。如果沒有聲音，請到手機的「設定 → 文字轉語音輸出」，在 Google 語音服務中下載「中文（台灣）」語音。

小小遊戲屋由個人開發者用心製作，希望能陪伴孩子快樂學習。有任何建議，歡迎在評論中告訴我們。
```

## 撰寫注意事項

Google Play 的中繼資料政策不允許在**應用程式名稱**與**圖示**中使用「免費」「最佳」「第一名」等宣傳或排名字眼，也不建議在說明中堆疊關鍵字或提及其他 App。以上文字已依此撰寫；日後修改時請留意。

## 重新產生截圖

遊戲畫面有大幅改動時，截圖需要重拍。手機版用 360×640 視窗、3 倍解析度（選單用 540×960、2 倍，以呈現兩欄），平板版用 1280×800 視窗、1.5 倍解析度，均以網頁版擷取。
